# ArenaGT Lite
Laboratorio 4 de Programación Orientada a Objetos. Aplicación de consola en Java para registrar equipos, organizar encuentros de fútbol sala y baloncesto, programar exhibiciones y consultar la tabla de posiciones y el calendario.

## Requisitos

- JDK 11 o posterior, con los comandos `java` y `javac` disponibles.
- Una terminal ubicada dentro de la carpeta `ArenaGT_Lite`.
